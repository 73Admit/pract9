# Практическая работа №9 — рекомендательная система по играм Steam

Автор: Евсенин Даниил Павлович, группа П-2-23
Дисциплина: «Технология разработки и защиты баз данных»

Рекомендательная система методом **взвешенного перебора**: для текстового запроса
пользователя система перебирает все игры каталога, начисляет каждой баллы за совпадение
жанра и за ключевые слова-характеристики и возвращает топ-N игр с процентом
совместимости.

## Данные

`data/games.csv` — каталог из **11 546 игр Steam**, собранный из датасета
[Steam Games Dataset 2025](https://www.kaggle.com/datasets/srgiomanhes/steam-games-dataset-2025)
(оставлены выпущенные игры минимум с 50 отзывами) и дополненный средним онлайном
из датасета практической работы №1 (Steam Monthly Average Players) по ключу `steam_appid`.

Поля: `name`, `developers`, `genres_str`, `categories_str`, `release_year`, `price`,
`rating` (доля положительных отзывов), `total_reviews`, `metacritic`, `avg_online`,
`peak_online`, `n_achievements`, `is_multiplayer`, `is_singleplayer`.

## Как начисляются баллы

* совпадение жанра — **45 баллов** за каждый распознанный жанр;
* ключевые слова-характеристики — до 35 баллов, пропорционально нормированному
  значению признака: «популярная» → число отзывов, «онлайн» → средний онлайн,
  «новая» → год выпуска, «дешёвая» → цена, «бесплатная» → цена равна нулю,
  «высоко оценённая» → доля положительных отзывов, «кооператив» → многопользовательский
  режим, «одиночная» → одиночный режим, «с достижениями» → наличие достижений;
* до 5 баллов добавляется за общий рейтинг, чтобы при равенстве выше шли лучшие игры;
* процент совместимости = набранные баллы / максимально возможные по этому запросу.

Слова «слабые», «худшие», «плохие» переключают режим на поиск игр с наименьшим баллом.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
```

**Консоль:**
```bash
python console.py
```

**Веб-интерфейс:**
```bash
python app.py
```
Открыть http://127.0.0.1:5000

**Telegram-бот:**
1. Написать [@BotFather](https://t.me/BotFather) команду `/newbot`, придумать имя
   и получить токен.
2. Скопировать `.env.example` в `.env` и вписать токен в строку `BOT_TOKEN=`.
3. Запустить:
```bash
python bot.py
```

## Возможности

* подбор топ-5 (или топ-10) игр по текстовому запросу с процентом совместимости
  и расшифровкой начисленных баллов;
* цикл ввода запросов в консоли;
* поиск игры по названию;
* поиск по диапазону характеристик (цена, рейтинг, онлайн, год, число отзывов);
* топ самых слабых игр;
* отзывы пользователей с оценкой 1–5 и статистика по играм;
* статистика по ранее введённым запросам: частые запросы, востребованные жанры;
* персональные рекомендации по истории запросов и оценок;
* обучение модели предпочтений (логистическая регрессия) на накопленных отзывах;
* звуковое сопровождение: Web Audio API в браузере, `winsound.Beep` в консоли;
* Telegram-бот со всеми теми же функциями.

## База данных

SQLite `data/recsys.db` создаётся автоматически при первом запуске.

* `queries(id, user_id, query, genres, top_app, top_name, source, created)` — история
  запросов, поле `source` различает веб, консоль и Telegram;
* `reviews(id, user_id, app_id, name, rating, text, created)` — отзывы с оценкой 1–5.
